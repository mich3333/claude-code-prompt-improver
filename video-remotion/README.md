# הסיכום השבועי של AI · Remotion

רילס אנכי (‎1080×1920, 30fps, 58 שניות) בפורמט "אווטאר מסביר":
- רקע גלים כחול
- כרטיס תוכן לבן עם תג ‎@מקור
- כותרת גדולה
- אווטאר בפינה התחתונה

הסרטון בנוי בקוד עם [Remotion](https://www.remotion.dev). את התוכן מחליפים בקובץ אחד, `src/scenes.ts`.

## הפעלה

```bash
cd video-remotion
npm install
npm run studio        # תצוגה מקדימה בדפדפן, עם עריכה חיה
npm run render        # out/weekly-ai.mp4
```

### הקבצים האישיים

הקבצים האלה נשמרים ב-`public/` ולא נכנסים ל-git:

| קובץ | מה זה |
|---|---|
| `public/avatar.jpg` (או `.png` שקוף, או `.mp4`) | המגיש |
| `public/poses/point.png` וכו' | תנוחות לפי סצנה: `talk`, `point`, `laptop`, `hold` |
| `public/voice.mp3` | הקריינות |

מעבירים אותם לרינדור כ-props:

```bash
npx remotion render WeeklyAI out/weekly-ai.mp4 \
  --props='{"avatar":"avatar.jpg","poses":{"point":"poses/point.png"},"voice":"voice.mp3","captions":false}'
```

בלי `avatar`, מופיעה במקום המגיש דמות זמנית. כשאין עדיין קריינות, `captions: true` מציג את טקסט הקריינות ככתוביות.

## "2026: שנת ה-AI" (כ-25 שניות)

קומפוזיציה שנייה בשם `AI2026`, ומרנדרים אותה עם `npx remotion render AI2026 out/ai-2026.mp4`. היא בנויה משלושה שלבים:
1. 22 כרטיסי כותרות עפים פנימה מכל הכיוונים, בתלת-ממד, ונערמים.
2. הכרטיסים מסתדרים לקיר לפי חודשים, ינואר עד אוקטובר, והמצלמה נוסעת לאורכו.
3. הכל מתפזר לעבר המצלמה, ונחשפת הכותרת.

את הכותרות עורכים ב-`src/year2026.ts`. הכותרות מנוסחות על ידינו, ולא מועתקות מהכתבות. בכל כרטיס מופיעים שם כלי התקשורת והתאריך, ופריטים שנשענים על דיווח אחד בלבד מסומנים "לפי דיווח".

### הכתבות עצמן

כשכרטיס מודגש, מופיע מעליו צילום של ראש הכתבה המקורית. הצילומים נשמרים ב-`public/articles/` ולא נכנסים ל-git, כי אלה דפים של צד שלישי. כל כרטיס מצביע על הצילום שלו בשדה `shot` ב-`src/year2026.ts`, ועל הכתבה עצמה בשדה `url`.

כדי לצלם מחדש: צילום מסך ברוחב 1280 של כל `url` (למשל דרך Firecrawl), ואז חיתוך לאזור הכותרת ביחס 940:600, כדי שהכותרת לא תיחתך בצדדים. כרטיס בלי `shot` מציג במקום הצילום אייקון מונפש.

### קריינות עם כתוביות מונפשות

כשיש הקלטה, הכתוביות מופיעות מילה אחרי מילה, והמילה שנאמרת ברגע זה צבועה בזהב. בנוסף, המצלמה עוברת לכל חודש בדיוק כשהוא נאמר, והכותרת "2026" נוחתת על ה-"2026" האחרון בקריינות.

1. שמים את ההקלטה ב-`public/voice-2026.mp3`.
2. מתמללים עם תזמון לכל מילה, למשל ב-ElevenLabs Scribe. אפשר דרך מסך הכתוביות האוטומטיות ב-ClipCraft, ואפשר לבקש מ-Claude.
3. מכינים קובץ `props.json`:
   ```json
   { "voice": "voice-2026.mp3", "words": [{ "text": "2026.", "start": 0.3, "end": 0.9 }] }
   ```
   ברשימת `words` נכנסות כל המילים מהתמלול, לא רק הדוגמה.
4. מרנדרים: `npx remotion render AI2026 out/ai-2026.mp4 --props=props.json`

אורך הסרטון נקבע לפי אורך הקריינות. קומפוזיציית `AI2026Preview` מציגה את התסריט עם תזמון משוער, כדי לראות איך זה ייראה עוד לפני ההקלטה.

## מהדורת חדשות עם מגיש מונפש (כ-39 שניות)

קומפוזיציה בשם `NewsCast`, בנויה כמו מהדורת חדשות:
- מגיש מצויר ומונפש מאחורי דסק. הפה זז לפי תזמון המילים, הוא ממצמץ, מטה את הראש, ומרים יד כשמתחילה ידיעה.
- מסך גדול מאחוריו, שמציג את הכתבה האמיתית של כל ידיעה עם האייקון והמספר.
- כותרת תחתונה "מבזק" עם הלוגו, כלי התקשורת והתאריך.
- פס מבזקים רץ ותג LIVE.

את התסריט עורכים ב-`NEWS_SCRIPT` שבקובץ `src/NewsCast.tsx`. כל שורה היא פתיחה, ידיעה (מספר כרטיס מתוך `src/year2026.ts`) או סיום.

- **תצוגה מקדימה:** `NewsCastPreview` מציג את המגיש מדבר בקצב משוער.
- **עם הקלטה:** מעבירים `voice` ו-`words` כמו ב-AI2026. המילים מתחלקות לשורות התסריט לפי מספר המילים בכל שורה, ולכן ההקלטה צריכה לעקוב אחרי התסריט.
- **עם מגיש אמיתי:** מעבירים `"anchor": "avatar.mp4"` (למשל סרטון מ-HeyGen) או תמונה, והם יופיעו במקום הדמות המצוירת.

```bash
npx remotion render NewsCast out/ai-news.mp4 --props=props.json
```

## השוואות: מי מנצחת? (כ-27 שניות)

קומפוזיציה בשם `Versus`. היא פותחת עם שני הלוגואים ו-"VS", ואחר כך עוברת סיבוב אחרי סיבוב. בכל סיבוב יש מדד אחד עם המספר והמקור של כל צד, החברה שמובילה מקבלת מסגרת זהב, והניקוד למעלה מתעדכן. בסוף מופיעה התוצאה וקריאה לתגובות.

את ההשוואות עורכים ב-`src/versus.ts`. כל השוואה היא רשומה ב-`MATCHES`, ומרנדרים אותה כך:

```bash
npx remotion render Versus out/vs.mp4 --props='{"match":"openai-anthropic","voice":null}'
```

כללים:
- סיבוב נכנס רק כשלשני הצדדים יש נתון שאפשר להשוות, ממקור עם תאריך.
- כשלצד אחד אין נתון, כותבים זאת במפורש.
- השורה התחתונה היא רק סכום הסיבובים, לא דעה.

## סרטון הסבר: הסקיל של Remotion (כ-37 שניות)

קומפוזיציה בשם `SkillExplainer`, בפורמט של סרטוני "מדבר מול מצלמה":
- כותרת קבועה למעלה.
- מסך זוהר באמצע שמתחלף בכל משפט: הריפו `remotion-dev/skills`, פקודת ההתקנה ורשימת הסקילים.
- בפתיחה ובשלוש הדוגמאות מופיע מחשב נייד עם שיחת צ'אט: הבקשה מוקלדת בעברית, ה-AI עונה בשורה, והסרטון שנבנה מהבקשה מופיע בתוך הצ'אט ומתנגן. עיצוב הצ'אט שלנו, לא העתק של ממשק של מוצר מסוים.
- מילה אחת גדולה של כתוביות.
- המגיש בכרטיס למטה.

כדי שהדוגמאות יתנגנו, צריך להעתיק את הסרטונים המרונדרים ל-`public/demos/`: `ai-news.mp4`, `openai-vs-anthropic.mp4` ו-`ai-2026-articles.mp4`.

כשמצלמים את עצמך:
1. שמים את הצילום ב-`public/face.mp4`.
2. מתמללים אותו עם תזמון לכל מילה.
3. מרנדרים עם `--props='{"face":"face.mp4","voice":null,"words":[...]}'`.

הסאונד מגיע מהצילום, וכל מסך מתחלף כשמתחיל המשפט שלו. את התסריט עורכים ב-`SKILL_SCRIPT`. מספר הכוכבים בריפו (5.2k) נכון ל-16.10.2026.

## הסגנון שלי: `MyReel`, מהקלטה ועד פרסום

זה העיצוב הקבוע של הרילסים שלך:
- ההקלטה שלך, בלי עיבוד, בתוך מסגרת ירוקה דקה על רקע אפור.
- פס התקדמות ירוק למעלה.
- משפט פתיחה בתחילת הסרטון.
- כתוביות מילה-מילה, והמילה שנאמרת מקבלת קו ירוק מתחתיה.
- B-roll בשתי צורות:
  - `split`: את/ה למעלה, והתוכן למטה.
  - `full`: התוכן במסך מלא, והפנים בעיגול בפינה.
- כרטיס סיום עם השם שלך.

התנועות בנויות לפי כללי האנימציה של Emil Kowalski:
- ease-out חזק לכל כניסה.
- ease-in-out לתזוזה על המסך.
- שום דבר לא גדל מאפס.
- השהיה קצרה בין אלמנטים שנכנסים זה אחרי זה.

כל ערכי התנועה נמצאים ב-`src/motion.ts`.

### הסקילים בפרויקט

בתיקייה `.claude/skills/` מותקנים:
- `remotion-best-practices`: הסקיל הרשמי של Remotion.
- `animate`, `emil-design-eng`, `review-animations`, `improve-animations`: הסקילים של Emil Kowalski, ברישיון MIT. הרישיון בקובץ `EMIL-LICENSE`.

כשפותחים את התיקייה `video-remotion` ב-Claude Code, הסקילים נטענים לבד.

### הזרימה

1. **הקלטה:** מקליטים את עצמך ושמים את הקובץ ב-`public/face.mp4`.
2. **תמלול:** מתמללים עם תזמון לכל מילה. אפשר לבקש מ-Claude Code ("תמלל את face.mp4"); הסקיל של Remotion מסביר איך לעשות את זה מקומית עם Whisper. התוצאה היא רשימת מילים בפורמט `Caption`, ומכינים ממנה קובץ `reel.json`. אפשר להיעזר בדוגמה שב-`src/reel.sample.ts`:
   ```json
   {
     "face": "face.mp4",
     "captions": [{ "text": " בניתי", "startMs": 600, "endMs": 900, "timestampMs": 750, "confidence": null }],
     "hook": "בניתי עורך וידאו משלי",
     "hookMs": 2600,
     "broll": [{ "src": "screen.mp4", "startMs": 4200, "endMs": 8200, "layout": "split" }],
     "handle": "@השם_שלך",
     "cta": "עקבו לעוד",
     "durationSec": 42
   }
   ```
3. **רינדור:** `npx remotion render MyReel out/reel.mp4 --props=reel.json`
4. **פרסום:** `npm run publish -- --file out/reel.mp4 --caption "..." --to instagram,tiktok --video-url https://...`

### פרסום אוטומטי לאינסטגרם ולטיקטוק

הפרסום משתמש ב-API הרשמיים, בלי שירות ביניים. מעתיקים את `.env.example` ל-`.env` וממלאים את הפרטים. את `.env` לא מעלים ל-git.

**אינסטגרם** (Instagram API with Instagram Login):
- החשבון צריך להיות מקצועי, Business או Creator.
- פותחים אפליקציה ב-developers.facebook.com, עם ההרשאות `instagram_business_basic` ו-`instagram_business_content_publish`, ומוציאים טוקן לטווח ארוך. הוא תקף 60 יום, וחידוש שלו: `npm run publish -- refresh-instagram`.
- אינסטגרם מוריד את הסרטון מקישור ציבורי, ולכן צריך להעלות את ה-MP4 למקום עם קישור ישיר ולהעביר אותו ב-`--video-url`. אפשר לפרסם עד כ-100 פוסטים ב-24 שעות.

**טיקטוק** (Content Posting API):
- פותחים אפליקציה ב-developers.tiktok.com עם ההרשאות `video.upload` ו-`video.publish`.
- ברירת המחדל היא `--tiktok-mode inbox`: הסרטון נשלח כטיוטה, ומסיימים את הפרסום באפליקציה של טיקטוק.
- `--tiktok-mode direct` מפרסם ישר, אבל עד שהאפליקציה עוברת את הבדיקה של טיקטוק, אפשר לפרסם כך רק כ"פרטי" (`SELF_ONLY`), ורק מחשבון פרטי.
- הטוקן תקף 24 שעות. חידוש: `npm run publish -- refresh-tiktok`.

תמיד כדאי להריץ קודם עם `--dry-run`. במצב הזה הסקריפט רק מדפיס את הבקשות, בלי לשלוח כלום.

## כל שבוע מחדש

עורכים את `src/scenes.ts`. כל סצנה היא אובייקט אחד, עם:
- זמן התחלה וסיום
- קריינות
- תנוחה
- תג מקור
- כותרת
- סוג תוכן אחד מתוך: `logos`, `post`, `counter`, `timeline`, `bars`, `outro`

השדה `check` מסמן מה עוד צריך לאמת לפני פרסום. הוא לא מוצג בסרטון.

### ציוצים

בסצנה מסוג `post` עדיף לשים **צילום מסך אמיתי** של הפוסט ב-`public/posts/`, ולקשר אליו בשדה `screenshot`. בלי צילום, הסצנה מציגה ציטוט מיוחס, שבכוונה לא מעוצב כמו פוסט ב-X. בניית "כרטיס ציוץ" מזויף אסורה לפי כללי התצוגה של X.

### לוגואים

הלוגואים מגיעים מהחבילה Simple Icons, בצבע הרשמי של כל מותג. אין לשנות את הצבע, העיוות או הפרופורציה, אלא רק להזיז ולשנות גודל.

ב-Simple Icons אין את OpenAI ו-xAI, ולכן הם מופיעים כשם כתוב. אם רוצים אותם, מורידים את הקובץ הרשמי מעמודי המותג של החברות.

רישיון CC0 של Simple Icons חל על החבילה, לא על הסימנים המסחריים. בתיאור הסרטון צריך להופיע "לא בחסות ולא בשיתוף עם אף חברה המוצגת".

### רינדור בסביבה בלי Chrome

אם Remotion לא מצליח להוריד דפדפן, מעבירים לו `--browser-executable` עם נתיב ל-`chrome-headless-shell`.
